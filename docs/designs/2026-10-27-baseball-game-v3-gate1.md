## ユーザーに聞くこと(Q-char にまとめた 1 件の中身)

**Q-char「キャラクターの作り込みの度合いと、打撃中の打者の顔」**(レビュー R2-m1)は、次の 2 つを一緒に聞く。

1. **度合い**: 最小 / 標準(推奨)/ 最大(次のサイクル)。工数と中身は本体の冒頭の表と character 分冊 §3-4-11。M15〜M21 のモックで見せる。
2. **打撃中の打者の顔**: **ホームの後方のカメラでは、打撃中の打者の顔は幾何的に見えない**(character 分冊 §3-4-9)。パワプロの打撃画面も打者は後ろ姿で、顔が見えるのはカットインとリプレイ。v3 は「投手の顔が正面で見える(1.30 倍)+打者の後ろ姿の作り込み(髪・耳・ヘルメット・背番号)+ワイプ(顔アップ)」で代える。**ユーザーが「打撃中も打者の顔が見えること」を求める場合は、カメラの構図そのもの(例: 打者を正面から映す別アングル)の再設計が必要で、v3 の範囲を超える**。M15(打撃・守備の全体)と M20(ワイプ)を見て「これでよい / 別アングルが要る」を選んでもらう。

### キャラクターのモックの作り方(M15〜M21。別担当)

製品コードではなく、使い捨ての three ハーネス(scratchpad)で作る。character 分冊 §3-4 の寸法・色・表情・フォームの仕様どおりに試作し(`BufferGeometryUtils`・`CanvasTexture` は使わず、顔は `DataTexture`(Linear+mipmap)に自前のラスタで描く = 製品と同じ制約)、`renderer.info.render` を記録する。**体は `SkinnedMesh`(体 1 + 輪郭 1 + 顔 1 + 背番号 1)で作り、M21 の draw call が設計値(近景 4・遠景 2)に収まるかを実測する**(収まらない・`SkinnedMesh` で問題が出るなら、設計の見直しとして報告する)。

| 度合い | 作るもの |
| --- | --- |
| 最小 | 全キャラクターに顔(8 表情)・髪・ヘルメット/帽子・肌色・ユニフォームの番号。体格は 1 種。フォームは現行のまま。投手 scale 1.30 |
| 標準 | 最小 + 20 人の個性(髪型 6・髪色 5・肌 5・体格 3・目 4)、肘・膝のあるフォーム(投手 3・構え 3・捕球・送球)、塁上の走者と進塁、ワイプ(94×94px)、品質ティア T0〜T3 の見え方 |
| 最大 | 標準 + スライディング・ベースカバーの数コマ、選手別の固有フォーム 2〜3 種、観客の動き、球場の看板・照明塔(参考絵) |

## 操作の流れ図(M12 の元)

**打撃**:

```
[指を置く]──カーソルは動かない(相対ドラッグの起点。演出中に置いた指は演出後にそのまま狙いの指になる)
   │
[スライド]──指の移動量だけカーソルが動く。終盤はロックオンで ● に吸い寄せられる
   │  投球がリリースされた瞬間: ● と大きなリングが出る → リングが D に向けて縮む
   ▼
[リングが ● にぴったり重なる瞬間に 指を離す] = スイング
   │   判定時刻 = 離した時刻 − 70ms
   │   ※ D−300ms より前の離しは「持ち替え」で無視 / 見逃すときは指を離さず待つ(D+250ms を過ぎた離しは見逃し)
   ▼
結果: 「ジャスト!/早い −62ms/遅い +48ms」+「芯/かすり」+ 位置ずれ(ゾーンの位置の十字と輪。DOM。900ms)+ 打球音・振動
   ▼
打球カメラ(接触の直後から追跡)→ (走者が動くなら内野カメラ)→ バナー・ワイプ → タップでスキップ可 → 次の球
別の振り方: 追加の指をタップ(その場で即スイング)/ スイングボタン / PC はクリック・Space
```

**投球**:

```
[球種チップを選ぶ(常時)]
   ▼
[指を置く]──照準が出る → [スライド]──照準が動く(散布円がブレの目安) → [指を離す] = 狙い確定、ゲージ開始
   ▼
リングが 0.9 秒かけて照準に向けて縮む(過ぎても 0.3 秒は縮み続ける。開始から 0.25 秒は停止できない)
   ▼
[リングが照準にぴったり重なる瞬間に タップ(どこでも / 「とめる!」)]
   → 質: ナイス(±40ms)/ グッド(±90)/ ふつう(±160)/ 失投
   ▼
windup 0.28 秒 → 投球 → 着弾 → 狙い(白)と着弾(シアン)の重ね表示(DOM。700ms)+ 「ナイスピッチ!」(質ごとのずれ: 13 / 25 / 37 / 65px 以上)
PC: マウスで狙い → クリック(確定)→ クリック/Space(停止)
```
