## 操作の流れ図(M12 の元)

**打撃(タップ方式。v2 の操作を維持)**:

```
[指を置く]──カーソルは動かない(相対ドラッグの起点。演出中に置いた指は演出のスキップになり、その指の離しではスイングしない)
   │
[スライド]──指の移動量だけカーソルが動く。終盤はロックオンで ● に吸い寄せられる(タップした時刻の位置で判定)
   │  投球がリリースされた瞬間: ● と大きなリングが出る → リングが D に向けて縮む
   ▼
[リングが ● にぴったり重なる瞬間に タップ] = スイング
   │   タップ = 指を動かさず(10px 以内)すばやく(180ms 以内)ポンと押して離す。判定時刻 = 押した時刻 − 70ms
   │   別の振り方: 合わせた指のまま、もう 1 本の指でタップ(その場で即スイング)/ スイングボタン / PC はクリック・Space
   │   ※ 長押し・ドリフトでスイングにならなかったときはヒント。見逃すときは何もしない(通過で見逃し)
   ▼
結果: 「ジャスト!/早い −62ms/遅い +48ms」+「芯/かすり」+ 位置ずれ(ゾーンの位置の十字と輪。DOM。900ms)+ 打球音・振動
   ▼
打球カメラ(接触の直後から追跡)→ (走者が動くなら内野カメラ)→ バナー・ワイプ・(長打なら「リプレイ」ボタン)→ タップでスキップ可 → 次の球
```

**投球**:

```
[球種チップを選ぶ(常時)]
   ▼
[指を置く]──照準が出る → [スライド]──照準が動く(散布円がブレの目安) → [指を離す] = 狙い確定、ゲージ開始
   ▼
リングが 0.9 秒かけて照準に向けて縮む(過ぎても 0.3 秒は縮み続ける。開始から 0.25 秒は停止できない)
   ▼
[リングが照準にぴったり重なる瞬間に タップ(どこでも / 「とめる!」)]
   → 質: ナイス(±40ms)/ グッド(±90)/ ふつう(±160)/ 失投
   ▼
windup 0.28 秒 → 投球 → 着弾 → 狙い(白)と着弾(シアン)の重ね表示(DOM。700ms)+ 「ナイスピッチ!」(質ごとのずれ: 13 / 25 / 37 / 65px 以上)
PC: マウスで狙い → クリック(確定)→ クリック/Space(停止)
```
