## ユーザーの不満の原因(レビューの仮説・順位つき)

1. 打撃「タイミングがカス」: ① 見た目のスイングが判定より 135〜285ms 遅れる(事実)。② ふつうでは窓内のタイミングが結果にほぼ効かない(事実)。③ 先読みの合図が弱く反応で押すと黙って捨てられる(事実+推測)。④ ロックオンでカーソルが指に追従しない(推測)。
2. 打球後「成り立っていない」: ① アウトなのにボールが野手の数 m 先に落ちて転がる。② 打者が打席に立ったまま走らない。③ テロップが動作より先。④ 野手の速さが不自然。⑤ 小さすぎて見えない。
3. 変化球・フォーム・投球操作: ① 画面上の変化量が 6〜10px(球径の 1/5 以下)。② 打者が素手に見える・バットが胸から生える。③ 投手が正面のまま腕を回すだけ・球が顔の横に湧いて止まる。④ コースを選べず常にど真ん中・ゲージもなく腕前が効かない。
